# LAMS - Laptop Asset Management System

Production-ready baseline monorepo for a multi-tenant Laptop Asset Management System (LAMS).

## Components
- Backend microservices (Spring Boot 3, Java 21)
- Frontend (React + TypeScript + Material UI)
- Docker compose local stack
- Kubernetes manifests (production-oriented)
- CI/CD workflow (GitHub Actions)

See `/docs` and `ARCHITECTURE.md` for details.
